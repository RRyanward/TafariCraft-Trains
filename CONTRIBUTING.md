# Contributing to TafariCraft - Trains

TafariCraft - Trains is currently under active development.

Before submitting code, please open an issue describing the bug, compatibility problem, or proposed change so that work can be coordinated.

## Development Target

- Minecraft 1.20.1
- Forge 47.3.22
- Java 17

## Contributions

When contributing code or assets:

1. Do not submit copyrighted third-party material without appropriate permission.
2. Clearly identify whether work is original or derived from legacy Traincraft material.
3. Preserve applicable attribution and licensing information.
4. Keep changes focused and document runtime testing where practical.
5. Avoid removing legacy credits or license notices.

Because this project is derived from Traincraft material covered by a custom license, contributors should review `LICENSE.md`, `NOTICE.md`, and `CREDITS.md` before contributing.
