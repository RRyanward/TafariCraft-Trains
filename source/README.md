# TafariCraft - Trains — Development Source

**TafariCraft - Trains** is an unofficial modernization and port of the classic **Traincraft** Minecraft mod to **Minecraft 1.20.1 / Forge 47.3.22 / Java 17**.

This source snapshot is maintained as a development backup for the TafariCraft - Trains project. It is **not** an official Traincraft release and does not claim endorsement by the original Traincraft authors or maintainers.

## Project identity

- Public project name: **TafariCraft - Trains**
- Internal compatibility mod ID: `traincraft`
- Minecraft: **1.20.1**
- Forge: **47.3.22**
- Java: **17**
- Repository: https://github.com/RRyanward/TafariCraft-Trains

The internal `traincraft` mod ID is intentionally retained during development to avoid breaking existing registries, resource paths, configs, saves, and compatibility work. A full identifier migration can be evaluated separately after the mod is complete.

## Development status

This project contains substantial porting, rewrites, compatibility work, bug fixes, and new systems for modern Minecraft/Forge, including work on locomotives, rolling stock, coupling, train physics, steam systems, GUIs/HUDs, and track behavior.
