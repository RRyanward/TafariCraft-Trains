# Changelog

All notable public changes to **TafariCraft - Trains** will be documented here.

The project is currently under active development and has not yet reached its first public release.

## Unreleased

### Added
- Minecraft 1.20.1 / Forge foundation
- Steam locomotive gameplay systems
- Functional tenders and rolling stock
- Multi-car coupling and consist handling
- Passenger seating
- Freight and caboose support
- Boiler temperature and overheating systems
- Coal and water consumption/supply
- Classic-inspired locomotive and tender interfaces
- Track, curve, slope, and railway compatibility work

### Changed
- Reworked legacy Traincraft systems for modern Forge/Minecraft APIs
- Reworked locomotive traction and mass behavior
- Reworked coupling behavior for forward and reverse operation
- Reworked train movement over hills and curves
- Reworked entity rendering and synchronization

### In Progress
- Additional track compatibility
- Additional locomotives and rolling stock
- Runtime regression testing
- Public release packaging
- Documentation and release notes
